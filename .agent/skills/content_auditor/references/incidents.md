# 사고 이력 — 규칙의 근거

SKILL.md 의 규칙이 왜 있는지에 대한 기록. 규칙을 완화하고 싶을 때 먼저 읽는다.
**여기 적힌 것은 전부 실제로 이 저장소에서 일어난 일이다.**

## 2026-03 애드센스 반려 — "가치가 별로 없는 콘텐츠"

반려 시점의 상태:

| | 당시 | 2026-09 |
|---|---|---|
| 칼럼 평균 | 1,749자 | 2,142자 |
| 도서 평균 | 381자 | 1,290자 |
| 홈 서버 HTML | **61자 (`Loading...`)** | 1,837자 |
| 무출처 통계 | 다수 | 정리 |

크롤러 관점에서 이 사이트에는 색인할 콘텐츠가 사실상 없었다. 사람이 브라우저로
보면 멀쩡했지만 구글이 받는 HTML 은 빈 껍데기였다. 반려 사유가 그 관점에서는
정확했다.

**교훈**: 사람이 보는 화면과 크롤러가 받는 HTML 은 다를 수 있다. 소스만 보고
판단하지 않는다.

## 면책 조항 중복 (2026-09-09)

스킬이 "칼럼 하단에 면책 조항 블록을 넣으라"고 지시하고 있었는데, 페이지
컴포넌트도 같은 문구를 렌더하고 있었다. 결과적으로 한 페이지에 두 번 출력됐다.

더 나쁜 것은 발견 경위다. 나는 MDX 파일 안만 검사하고 "중복 0건"이라고 보고했다.
실제 렌더 화면은 확인하지 않았다. 유저가 화면을 보고 찾아냈다.

**교훈**: 소스 검사는 렌더 검사를 대체하지 못한다.

## 계산기 딥링크의 inflation 기본값 (2026-09-09)

`/calc?tab=compound&...` 딥링크에서 `inflation` 파라미터를 빠뜨리면 계산기가
**기본값 3 을 적용한다.** 본문 수치를 인플레이션 미반영으로 계산해 뒀다면 조용히
어긋난다. 이 원인으로 4개 칼럼의 수치가 틀려 있었다.

`salary-to-billion` 에서는 본문을 15억 9,964만으로 고치고 3줄 요약은 "16억 5천만"
그대로 두어 한 글 안에서 수치가 어긋난 적도 있다.

**교훈**: 수치는 계산해서 대조한다. 고칠 때는 본문·요약·결론을 함께 고친다.

## RIA 칼럼 삭제 (2026-09-09)

국내시장복귀계좌(RIA)의 감면율과 적용 기한을 1차 출처로 확인하지 못했다.
law.go.kr 검색 결과가 렌더되지 않았고 기재부 페이지는 리다이렉트 루프였다.

확인되지 않은 세법 수치를 완화 표현으로 남겨 두는 것도 선택지였지만, YMYL
페이지에서 그건 위험을 줄이는 게 아니라 미루는 것이다. 글 전체를 내렸다.

같은 시기 ISA 칼럼은 **개정안을 시행 중인 법으로 서술**하고 있었다. 조세특례제한법
제91조의18(시행 2026.1.1, 법률 제21223호)로 대조해 총 1억원 / 비과세 200만·400만 /
9% / 3년으로 정정했다.

**교훈**: 개정안과 시행법을 구분한다. 확인 못 하면 쓰지 않는다.

## canonical 이 전 페이지를 홈으로 가리킴 (2026-09-10)

루트 레이아웃이 `canonical: "https://thelazyrich.me"` 를 절대 주소로 박아 두었고,
칼럼·도서 라우트가 덮어쓰지 않았다. 결과적으로 **55개 콘텐츠 페이지가 "나는 홈의
복제본"이라고 선언**하고 있었다.

다만 서치 콘솔을 보면 102개가 색인돼 있었다. 구글이 canonical 을 힌트로만 취급하고
무시한 것으로 보인다. 나는 처음에 이걸 "색인 안 됨 42건의 원인"이라고 단정했는데
틀렸다. 42건은 전부 `_next/static` 빌드 파일이었다.

**교훈**: 새 라우트를 추가하면 canonical 을 함께 넣는다. 그리고 증거 없이 인과를
단정하지 않는다.

## CSP 가 광고를 5개월간 차단 (2026-04-09 ~ 2026-09-10)

`16dd465` 가 CSP 를 도입하면서 `frame-src` 를 넣지 않아 카카오 애드핏 iframe 이
전부 막혔다. 다음 날 `7558c06` 이 복구를 시도했지만 `*.kakao.com` 과
`*.daumcdn.net` 만 추가했다. 애드핏의 실제 iframe 호스트는 `t1.kakaocdn.net` 이라
어느 쪽에도 걸리지 않았다.

GA4 도 같은 이유로 한 번도 동작하지 않았다. `script-src` 에 googletagmanager 가
없었다. 내가 그걸 고칠 때도 `*.analytics.google.com` 만 넣어 상위 도메인인
`analytics.google.com` 이 계속 막혔다.

**교훈**: CSP 위반은 에러 없이 빈 공간으로만 나타난다. 스크립트 로드 성공을 동작
확인으로 착각하지 않는다. 실제 요청이 나갔는지를 확인한다.
