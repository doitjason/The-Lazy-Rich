# 렌더링 함정

본문이 옳아도 화면에서 깨지는 경우. **소스만 보고 통과시키지 않는다.**

## 칼럼 — `src/app/columns/[id]/page.tsx`

| 동작 | 조건 | 결과 |
|---|---|---|
| 문단 → `h3` 승격 | 50자 미만 + 문장부호 없음 | 리듬용 짧은 문장이 제목이 됨 |
| 광고 3분할 | 본문 1,600자 이상 **그리고** 문단 10개 이상 | 미달 시 2분할(광고 2개) |
| 요약 카드 | `3줄 요약` 문자열 탐지 | 문자열을 바꾸면 카드와 광고 배치가 함께 깨짐 |
| 면책 조항 | 무조건 렌더 | MDX 에 또 넣으면 두 번 출력 |

**대응**: 짧은 문장은 반드시 마침표로 끝낸다. 소제목은 `##`/`###` 로 명시한다.

## 도서 — `src/app/books/[id]/page.tsx`

블록은 `\n\n` 으로 나뉜다.

| 동작 | 조건 | 결과 |
|---|---|---|
| 블록 → `h4` 승격 | 40자 미만 + 마침표 없음 | 짧은 문단이 제목이 됨 |
| 제목 연속 | 제목 블록이 2개 연달아 | 본문 없는 제목이 화면에 노출 |
| 불릿 목록 | 한 블록 안의 `- ` 로 시작하는 줄 | `\n\n` 으로 나누면 각 줄이 별개 제목이 됨 |

**대응**: 불릿은 한 블록 안에서 단일 개행으로 잇는다. 문단을 삽입할 때 제목 바로
뒤에 다른 제목이 오지 않는지 확인한다. `npm run check:books` 가 제목 연속을 잡는다.

## 파일 형식

*   `src/content/columns/*.mdx` 는 전부 **CRLF**. 스크립트로 편집할 때 줄바꿈을 보존한다.
*   `src/data/books.ts` 의 `longDescription` 은 JSON 스타일 문자열이다. `\n` 이스케이프로
    들어 있으므로 직접 편집보다 스크립트로 파싱해 다루는 편이 안전하다.

## 확인 방법

```bash
npm run dev
```

새 칼럼 페이지를 열고 확인한다.

- [ ] 3줄 요약 카드가 정상 렌더
- [ ] 소제목이 `h2`/`h3` 로 출력
- [ ] 짧은 문장이 제목으로 잘못 승격되지 않음
- [ ] 광고 슬롯 3개
- [ ] **면책 조항이 한 번만** 출력

모바일 폭(`max-w-md`)에서도 본다. 데스크톱에서 적당한 문단이 휴대폰에서는 벽이 된다.
